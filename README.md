# SQL Learning Repository

This repository contains my SQL practice exercises and projects.

## Topics Covered

- Window Functions
  - LAG() and LEAD()
  - PARTITION BY and ORDER BY
  - NTILE() : divides the rows in a window into a specified number of percentiles
- Common Table Expressions (CTE)
- GROUP BY and Aggregate Functions
- Data Analysis
- Datetime functions
- String Functions:
  - REPLACE ()
  - CONCAT()
  - SUBSTR() , INSTR(),
  - REGEXP_SUBSTR() -- make program slower
  - LIKE
  - COALESCE()
- DATA analysis Applications
  - Duplicate Values
  - MIN / MAX Value Filtering
  - Pivoting: let transform rows into columns to summarize the data
  - Rolling Caculations
  - Imputing NULL values
