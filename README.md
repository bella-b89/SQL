- Window Functions

- GROUP BY and Aggregate Functions
- Data Analysis
- Datetime functions
- String Functions:

  - CONCAT()
  - SUBSTR() , INSTR(),
  - REGEXP_SUBSTR() -- make program slower
  - LIKE
